# etchebarne.net

Personal site of Martin Etchebarne. Vite, React, Tailwind CSS, shadcn/ui and the [dithercn](https://dithercn.dev) dither engine.

```bash
pnpm install
pnpm dev     # http://localhost:4321
pnpm build   # static site in dist/
```

Content (projects, experience, about) lives in `src/content.ts`. Pushing to `main` deploys to GitHub Pages.
